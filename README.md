# Weather-App
A responsive real-time weather app built with HTML, CSS &amp; JavaScript using the OpenWeather API. Supports city search, current location, temperature, humidity, wind speed, and more.
WeatherNow

A professional and responsive weather application built using HTML, CSS, and JavaScript. WeatherNow uses the OpenWeather API to display real-time weather information for cities around the world.

## API Key Setup

This project requires an OpenWeather API key to display live weather data.

Create an account on OpenWeather.
Generate your API key.
Open script.js.
Add your API key to the API configuration.

Example:

const API_KEY = "YOUR_API_KEY_HERE";

Important: Never upload your personal API key to a public GitHub repository.

## How to Run
Option 1: Open Directly

Open:

index.html

in your browser.

Option 2: VS Code
Open the WeatherNow folder in VS Code.
Install the Live Server extension.
Right-click index.html.
Select Open with Live Server.
The application will open in your browser.
